# Learn to read and write Devanagari

A single-file web app (`index.html`) for learning the Hindi script with spaced repetition.
No install, no server, no account. Progress is saved in your browser.

## Run it on your computer
Double-click `index.html`. It opens in your browser and works offline.

## Host it on GitHub Pages
1. Create a new repository on github.com (for example `akshar`).
2. Click **Add file → Upload files**, drop in `index.html` (and this README), then **Commit changes**.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, pick **main** and **/ (root)**, then **Save**.
4. After a minute or two it's live at `https://YOUR-USERNAME.github.io/akshar/`.

To update it later, upload a new `index.html` to the same repository.

## Moving your progress
Progress is stored per browser and per address, so the local file and the GitHub Pages version
keep separate progress. Use **Settings and backup → Export**, then **Import** on the other one.
